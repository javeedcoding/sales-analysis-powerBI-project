# Sales Analysis Power BI Project

A beginner-level sales analysis project using Power BI.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel/CSV

## Analysis

The dashboard analyzes sales, profit, quantity, categories, sub-categories and customers.

## Key Insights

- Total sales were around 432K.
- Total profit was around 24K.
- Around 6K quantities were sold across 500 orders.
- Electronics generated the highest sales.
- Clothing had the highest quantity sold.
- Furniture had the highest average order value.
- The dashboard allows filtering using date and category slicers.

## Dashboard

The Power BI dashboard contains KPI cards and charts for sales and category analysis.
